# Suthep — A Developer's World

พอร์ตโฟลิโอเล่าเรื่องภาษาไทย ผ่านโลก 3D สี่บท: พื้นดิน → ภูเขา → ท้องฟ้า → อวกาศ

## เริ่มใช้งาน

ต้องมี Node.js 22.12+ หรือ 24+

```sh
npm install
npm run dev
```

เปิด URL ที่ Vite แสดงใน terminal (ปกติ http://127.0.0.1:5173)

```sh
npm run build
npm run preview
```

นำโฟลเดอร์ `dist` ไปโฮสต์บน static hosting ได้ เช่น Vercel หรือ Netlify โดยตั้ง build command เป็น `npm run build` และ output directory เป็น `dist`

## ข้อมูลและการแก้ไข

- `public/Resume — Suthep Jantawee  Software Developer.pdf` — ไฟล์เรซูเม่ที่ผู้ชมดาวน์โหลด (ปุ่มดาวน์โหลดตั้งชื่อไฟล์เป็น `Suthep-Jantawee-Resume.pdf`) ส่วน `text Resume.txt` คือข้อมูลต้นฉบับแบบข้อความ
- `public/person1.jpg`, `public/person.png`, `public/image1.jpg` — รูปต้นฉบับของเจ้าของเว็บ (ภาพ hero, ภาพส่วนติดต่อ, ภาพขณะนำเสนองาน)
- `public/project/*.png` — ภาพหน้าจอโปรเจกต์ต้นฉบับ อ้างอิงจาก `image` และ `slideImages` ในข้อมูลโปรเจกต์
- `scripts/optimize-images.py` — สร้างไฟล์ WebP สำหรับเว็บจากรูปต้นฉบับ (`public/photos/*`, `public/project-web/*`, `public/project-web/thumbs/*`) รันด้วย `python3 scripts/optimize-images.py` (ต้องมี Pillow) ทุกครั้งที่เพิ่มหรือเปลี่ยนรูป
- `.vercelignore` — ตัดรูปต้นฉบับ (`public/project/*.png`, `public/person*.png|jpg`, `public/image1.jpg`) ออกจาก deploy บน Vercel เพราะหน้าเว็บโหลดเฉพาะ WebP ใน `public/project-web` และ `public/photos` ทำให้ output ลดจาก ~152 MB เหลือ ~10 MB (ต้นฉบับยังอยู่ใน repo สำหรับรันสคริปต์แปลงรูป) ถ้าเพิ่มรูปต้นฉบับโฟลเดอร์ใหม่ให้เพิ่มในไฟล์นี้ด้วย
- `data/personalProjects.ts` — โปรเจกต์ส่วนตัวทั้งหมด ใช้สร้างคลังโปรเจกต์ ค้นหา กรองหมวดหมู่ และลิงก์ GitHub/demo
- `data/workProject.ts` — โปรเจกต์จากงานประจำ
- `src/App.tsx` — เรื่องราว ประวัติการทำงาน ช่องทางติดต่อ และข้อมูล eKYB ที่เสริมจากเรซูเม่
- `data/skillCategories.ts` — หมวดเครื่องมือ/ทักษะ 8 หมวด ใช้สร้าง "แคมป์" บนภูเขา 3D และการ์ดทักษะที่โผล่ระหว่างไต่เขา (ป้าย `ClimbNote` ปิดท้ายบทพื้นดิน ตามด้วยช่วง `Climb` ระหว่างบทพื้นดินกับภูเขา) ถ้าอุปกรณ์ไม่มี WebGL จะแสดงเป็นตาราง `Toolkit` ธรรมดาแทน
- `src/Journey.tsx` — โลก low-poly ฉากเดียวแบบต่อเนื่อง สร้างด้วย Three.js เป็นเสาแนวตั้ง: เกาะ กระท่อม โต๊ะทดลอง → ภูเขาพร้อมทางเดิน ธงไมล์สโตน เต็นท์ → เมฆ บอลลูน เกาะลอย เครื่องบินกระดาษ → ดาวเคราะห์ จรวด ดาวเทียม ดาว กล้องไต่ขึ้นตามการเลื่อนหน้า พื้นหลังไล่สีตามระดับความสูง มี "นักวิ่ง" ตัวเล็กหนึ่งตัวเดินทางตลอดเรื่อง: ออกจากประตูกระท่อม วิ่งรอบเกาะ ไต่บันไดหินขึ้นยอดเขา กระโดดข้ามเมฆและเกาะลอย แล้วลอยตัว (ใส่หมวกอวกาศ) ผ่านดาวเคราะห์ไปหาจรวดและดาวเทียม ตำแหน่งผูกกับค่า progress ของกล้องที่ผ่าน easing เดียวกัน (`route` ในไฟล์) จึงเคลื่อนที่ลื่นตามการเลื่อนและอยู่ในแถบฉากที่โผล่เหนือการ์ดเนื้อหาเสมอ ท่าวิ่ง/กระโดด/ลอยคำนวณจากระยะทางที่เคลื่อนจริง ไม่ใช่เวลา บันไดหินบนภูเขาเป็นทางสลับฟันปลา (switchback) บนหน้าเขาที่หันเข้ากล้อง มีแคมป์ 8 จุดตามหมวดใน `data/skillCategories.ts` ทุกเฟรมที่เรนเดอร์จะ project ตำแหน่งแคมป์เป็นพิกัดจอ แล้วเขียน transform/opacity ให้การ์ด HTML (`.skill-card`) โดยตรง การ์ดใช้หน้าตาเดียวกับป้าย TOOLKIT (แผงโปร่ง eyebrow เป็น path ของหมวด + หัวข้อ + ชิป) โผล่ทันทีตามตำแหน่งเลื่อน (ไม่ผ่านการหน่วงเวลา) ทีละคู่ (แคมป์ซ้าย+ขวา = 1 จุดพัก รวม 4 จุด) แต่ละคู่ผูกกับค่า altimeter (`cardAltitudes` = 470 / 600 / 710 / 910 M) โผล่เต็มที่ค่านั้นและ fade เข้าในช่วง 20 M ก่อนหน้า การ์ดที่เคยแสดงแล้วจะค้างไว้เมื่อเลื่อนกลับขึ้นตลอดช่วงภูเขา (คู่ที่อยู่เหนือตำแหน่งปัจจุบันหรี่เหลือ 40%) และจางออกเมื่อเลื่อนกลับเข้า hero ต่ำกว่า 430 M (บนจอแคบค้างเฉพาะคู่แรก เพราะวางได้ทีละคู่) นักวิ่งตามไปแตะแคมป์ทีละจุด (ราว 50 M ต่อแคมป์) แล้วเดินต่อถึงยอดที่ราว 1,900 M แล้วนักวิ่งค่อยไต่ตามมาแตะแคมป์ทั้งสองของคู่ ภูเขาสูง 14 หน่วย (สูงขึ้น 40%) ทางแกว่งซ้ายขวาเพียง 0.27 เรเดียน แคมป์ทั้ง 8 อยู่ครึ่งล่างของเขา (ห่าง 1.15 หน่วย) เส้นทางเดินยาวราว 19 หน่วย (ครึ่งหนึ่งของแบบแรก) ส่วนท้องฟ้าและอวกาศถูกยกขึ้นตามในกลุ่ม `upper` บน desktop เห็นคู่ปัจจุบันและคู่ก่อนหน้า คู่เก่ากว่านั้นจางลง การ์ดฝั่งเดียวกันจัดวางแบบ skyline (ดันขึ้นพ้นใบก่อน หรือย้ายไปคอลัมน์นอกเมื่อจอเตี้ย) จึงไม่ทับกัน บนจอแคบเห็นทีละคู่
- `src/journeyMath.ts` — คณิตศาสตร์แปลงตำแหน่งสกรอลล์เป็นความคืบหน้าของบท ความสูง (altimeter) และเส้นโค้งการเดินทาง ใช้ร่วมกันโดย App และ Journey
- `src/style.css` — สี ฟอนต์ layout และ responsive styles

การ์ดโปรเจกต์ใช้ภาพหน้าจอจริงจาก `public/project-web/thumbs` (โหลดแบบ lazy) และเมื่อเปิดรายละเอียดจะมีแกลเลอรีเลื่อนดู `slideImages` ทั้งหมดจาก `public/project-web` โปรเจกต์ที่ไม่มีภาพหน้าจอ (เช่น API แบ็กเอนด์) ยังใช้ concept visual ที่สร้างด้วย CSS เหมือนเดิม ภาพ hero ของเจ้าของเว็บถูกตัดพื้นหลังดำออกให้โปร่งใสโดยสคริปต์ จึงวางบนพื้นหลังสีใดก็ได้

ฉาก 3D เรนเดอร์ครั้งเดียวเป็นพื้นหลังแบบ fixed แล้วเนื้อหาเลื่อนซ้อนด้านบน ระหว่างบทมีช่วง "เดินทาง" (`.travel`) ให้กล้องไต่ขึ้นและสีพื้นหลังเปลี่ยน (ครีม → เขียวหมอก → ฟ้า → น้ำเงินเข้มพร้อมดาว) header, rail และแคปซูลสถานะเปลี่ยนธีมตามบทผ่าน `data-chapter` บนมือถือเนื้อหาอยู่บนแผงกระจกโปร่งเพื่อให้ยังเห็นฉาก รองรับ pointer parallax, ปุ่มพักภาพเคลื่อนไหว, `prefers-reduced-motion`, หยุดเรนเดอร์เมื่อแท็บถูกซ่อน และมี fallback เมื่ออุปกรณ์ไม่รองรับ WebGL เนื้อหาหลักยังอ่านได้ตามปกติ

ฟอนต์โหลดจาก Google Fonts และมี system fallback หากไม่มีอินเทอร์เน็ต ไม่มี backend, analytics หรือการส่งข้อมูลส่วนตัวผ่านฟอร์ม ปุ่มติดต่อใช้ mailto และลิงก์ตามข้อมูลที่ให้มา
